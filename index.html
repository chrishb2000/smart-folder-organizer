Reglas personalizadas (prioridad sobre las categorias)

Archivos duplicados

Grupos de archivos con el mismo contenido (hash MD5). Elimina las copias conservando una copia. Usa el modo seguro para poder restaurarlas.

Imagenes casi-duplicadas

Detecta fotos redimensionadas, re-saved o recortadas usando hash perceptual (dHash), como hacen herramientas profesionales. Todo 100% local.

Renombrado masivo por lotes

Renombra cientos de archivos con patrones. Tokens: {nombre}, {nombre_limpio}, {fecha}, {anio}, {mes}, {dia}, {mtime}, {carpeta}, {sec}, {sec2}, {extension}, {tamano}.

Archivos mas grandes

Los 30 archivos de mayor tamano en las carpetas analizadas.

Limpieza de carpetas

Elimina carpetas vacias y archivos temporales (.tmp, .bak, .log, .old...) para liberar espacio de forma segura.

Integridad de archivos

Archivos cuya extension no coincide con su contenido real y archivos posiblemente corruptos.

Dashboard de estadisticas

Distribucion de espacio por categoria, carpetas mas pesadas, extensiones dominantes e historico de archivos por mes. Busca y filtra todos los archivos analizados.

Registro de acciones y deshacer

Cada accion queda registrada. Las acciones con cuarentena o movimientos pueden restaurarse pulsando "Restaurar".

Exportar informes profesionales

Genera un inventario CSV de todos los archivos analizados (con acciones de la sesion) o un informe HTML visual listo para imprimir o compartir.
